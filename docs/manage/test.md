# Test

cargo testでチェック
固定seed数個を何回か走らせ、スカラー指標を表示する。

「壊れてないか心配なとき」や「大きな変更を入れた後」に手動で叩く運用。
スナップショットはJSONでリポジトリに入れておけば、git diffで「前回からどう変わったか」も見える。

### 必要なもの
World::new(seed)でseedから初期化できること
World::run(n)でn tick走らせられること
World::metrics()で指標を取り出せること

### 指標
今：地形・河川が対象。

陸地セル数
標高の平均・分散
陸地の最大連結成分サイズ（≒最大大陸の大きさ）
大陸数（連結成分の数、面積閾値以上のもの）
河川流量の最大値
河川流量上位10本の合計
