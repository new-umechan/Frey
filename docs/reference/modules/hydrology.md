# 水の流れの考え方

この文書は、現在の水文モデルを、実装の細部ではなく概念として説明する。
関数名、内部フィールド名、式、個別パラメータの一覧はここでは扱わない。

## 役割

水文モデルは、地形と気候から、水がどこへ流れ、どこに集まり、どこを削り、どこへ堆積するかを近似する。
目的は、河川を細かく再現することではなく、地形・生態・社会が読める水の通り道と水アクセスを作ることである。

ここで扱う水は、長い時間スケールで平均化された流れである。
洪水、季節流、地下水、個別の河道変遷は直接扱わない。

## 更新

まず、各セルで水が流れやすい隣接セルを探す。
基本的には低い方へ流すが、地形が平らな場所や広がった斜面では、1本の流路だけに押し込めず、
複数方向へ分けて流す。

水が外へ出られない低地では、一時的な貯留として扱う。
貯留が深くなると、最も低いあふれ口から次の場所へ流れる。
これにより、閉じた窪地、湖、内陸盆地、あふれ出す経路を同じ考え方で扱う。

流路が決まると、上流から下流へ水を集める。
水が多く、斜面が急な場所では削る力が強くなる。
流れが弱くなる場所や低地では、運ばれた物質がたまりやすい。

地形が大きく変わったときは、流路そのものを作り直す。
地形が安定しているときは、流路を保ったまま流量だけを更新する。
これにより、計算量を抑えつつ、地形変化に遅れすぎない水系を保つ。

## 接続

水文は、地形の高さ、海面基準、気候から来る流出、氷の融け水を読む。
出力する流量、水アクセス、湖、侵食、堆積は、地形、生態、生業、集落の条件になる。

水文が計算した侵食と堆積は、最終的には地形側へ戻る。
ただし、水文は地形を直接好きに変えるのではなく、水がどこで削り、どこでためるかを示す。

## 参照している考え方

現在のモデルは、次の考え方を組み合わせた近似である。

- 水は基本的に低い方へ流れる
- 緩い地形では流れが分散し、急な地形では集中する
- 閉じた低地では水がたまり、あふれ口から次へ流れる
- 流量と勾配が大きい場所では侵食が強まる
- 流れが弱くなる場所では堆積が増える

## 意図的な近似

このモデルでは、地下水、季節洪水、河道の蛇行、細かな土砂粒径、短期の氾濫は直接扱わない。
また、すべての水塊を物理的に完全保存することよりも、長期の地形変化と水アクセスを安定して表すことを優先する。

そのため、流路は現実の川そのものではなく、セル上で水が通りやすい経路として読む。
