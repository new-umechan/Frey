# 地形とプレートの考え方

この文書は、現在の地形生成と地形更新を、実装の細部ではなく概念として説明する。
関数名、内部フィールド名、診断指標の一覧はここでは扱わない。

## 初期化

最初に球面メッシュを作る。
このメッシュの各セルが、以後の世界状態を持つ基本単位になる。

次に、セル上にゆるやかな背景分布を置く。
背景分布には、熱の高低、冷えやすさ、壊れやすさ、古く安定した領域になりやすい場所などが含まれる。
ここで作る値は、そのまま現実の物理量に対応するものではない。
むしろ「このあたりは裂けやすい」「このあたりは硬く残りやすい」といった傾向を
生成するための下地である。

その下地を何回か更新し、壊れやすい帯を育てる。
壊れやすさは、内部の熱、周囲との違い、既に弱くなっている場所の影響を受ける。
弱い場所はさらに弱くなりやすく、硬い場所はまとまった塊として残りやすい。

十分に弱い帯ができると、それを境界の候補として扱う。
境界に囲まれたまとまりのある領域を、1つの剛体的な区画として割り当てる。
この区画が、以後の更新でプレートに相当する単位になる。

この段階で重要なのは、プレート数を直接置いているわけではない、という点である。
先に弱い帯を作り、その結果として分かれた領域をプレートとして読む。
そのため、初期化の目的は「指定個数のプレートを作る」ことではなく、
弱い境界と強い内部が両方成立する状態を作ることである。

## 更新

時間が進むたびに、まず内部の熱に相当する量を更新する。
熱は、地形の高さ、境界の活動、火山活動、区画の性質に影響する。
同時に、冷え方の違いや古さの違いも、各区画の振る舞いに反映される。

次に、各プレートの動きを更新する。
プレートは完全に自由な流体ではなく、おおまかには硬い板として扱う。
そのため、各プレートには回転や移動の向きがあり、境界では隣り合うプレートどうしの
相対的な動きが現れる。

相対的な動きから、まず離反・収束・横ずれを判定する。
局所的な相対速度は境界を横切る法線成分と、境界に沿う接線成分へ分ける。
境界の両端が離れる向きを法線速度の正、近づく向きを負とし、
負の法線速度を収束、正の法線速度を発散、接線速度を横ずれの強さとして読む。
収束境界は地殻組成と沈み込み開始状態を使い、大陸衝突、開始前沈み込み、
沈み込み開始済みに分ける。開始前沈み込みは海洋地殻を即座に削除せず、
収束の継続と負浮力が十分になった場合に沈み込みへ遷移する。
近づく場所では、この収束状態に応じて押し上げや沈み込みに相当する変化が起きる。
離れる場所では裂け目や新しい地殻に相当する変化が起きる。
横にすれ違う場所では、高さよりも境界活動の強さが主に変化する。
これらは現実の境界分類をそのまま再現するものではなく、
地形生成に必要な違いを表すための簡略化である。

高さ、熱、火山活動のような連続量は、近傍セルへなめらかに伝わる。
プレート所属の正本は、固定icosphere上で全球を排他的に覆う `plate_id` である。共有境界の相対Euler速度から
境界を横切る移動量を求め、小数cell分を境界componentごとに蓄積する。整数cellへ達したら連続したpatchとして
移し、移動前後のplateが分断・孤立しない場合だけ所属変更を確定する。

これとは別に、プレートごとに永続化した球面上のmaterial elementが地殻物質を保持する。elementは初期プレートの
表面を三角形として保持し、プレートのEuler運動に従って移流する。固定メッシュへの投影は地殻組成、年齢、
coverage診断のために行い、markerの重なりや隙間から `plate_id` を再構成しない。

移流後は、境界の発散・収束・衝突に応じて material を更新する。
発散では新しい海洋 material を追加し、沈み込みでは条件を満たした海洋側を除去する。
衝突や変換境界では、重複と隙間を局所的に補正する。その後、投影されたmaterialから各セルの地殻組成と
地殻年齢を読み直す。materialのgap/overlapは物質収支の診断として残すが、プレート所属には変換しない。

これは球面 polygon の厳密な連続体移流ではなく、球面三角形 element と固定メッシュ投影による近似である。
element は内部変形せず剛体回転し、衝突時の上下関係や新しい海嶺 material の生成はメッシュ解像度で扱う。
その代わり、プレート内部の物質履歴、面積、発散・沈み込みによる局所的な増減を永続状態として保持する。

最後に、更新後の状態から地形や派生量を作り直す。
山地、海盆、火山活動、沈降、侵食や堆積との接続は、この段階で世界状態へ反映される。

## 接続

地形は、他の領域が読む地理的な条件を作る。
そのため、海陸、標高、境界活動、火山活動、侵食や堆積の反映は、
時間ステップごとに過剰にちらつかない形で更新する。

## 参照している考え方

現在のモデルは、次の考え方を組み合わせた近似である。

- 壊れやすさが蓄積すると、境界になりやすい帯が育つ
- 強い内部と弱い境界がそろうと、まとまったプレートとして扱える
- プレートはおおまかに剛体的に回転・移動する
- 境界の相対速度から、衝突、離反、横ずれ、沈み込みに相当する振る舞いを分ける
- 熱の蓄積と冷却の違いが、地殻の性質や火山活動に影響する
- 氷、水、堆積物は、長い時間で地形に戻る外力として扱う

実装方式の選定理由と比較した方式の履歴は、
[shared plate front の decision document](../../decisions/260822-topology-preserving-material-front.md) と
[persistent material の decision document](../../decisions/260716-persistent-material-ownership.md) に記録する。

## 意図的な近似

このモデルでは、岩石の破壊、マントルの流れ、断層の幾何、沈み込み帯の三次元構造を
直接解かない。
また、現実の地球の特定地域や特定時代を再現することも目的ではない。

代わりに、次の性質を優先する。

- 同じ初期条件から同じ世界が得られる
- 世界全体を長い時間進めても破綻しにくい
- 地形、気候、水文、生態、社会が同じセル状態を通して接続できる
- 計算量が大きくなりすぎない
- 変化の理由を、局所的な数値ではなく世界生成上の因果として説明できる

そのため、現実の地球物理としては粗い近似でも、
世界生成の基盤として一貫した結果を出すことを優先している。

persistent material の投影は、全球を覆う icosphere mesh を前提とする。geology を実行する
統合テストも、任意の局所 adjacency ではなく生成済み icosphere を使う。単tickの phase 契約は
level 1、数十tick進める timeline 契約は subcell plate が検証対象を妨げない level 2で確認する。

## 検証範囲

人工的な境界条件による verification では、相対運動から地形変化への変換について、
向き、符号、境界のどちら側へ出るか、境界付近への局在、法線・接線速度への依存を確認する。
これは更新則が意図どおり計算されることを確認するものであり、地形全体の科学的妥当性を
直接示すものではない。

実地球データによる validation では、境界種別、地殻種別、地殻年齢などの条件ごとに、
長期積分した地形または観測可能な地形関係を比較する。
現在の絶対標高と 1 tick の地形変化は直接比較しない。
