# 栽培・飼養の考え方

この文書は、現在の栽培・飼養モデルを、実装の細部ではなく概念として説明する。
関数名、内部フィールド名、個別の作物名・家畜名、式、個別パラメータの一覧はここでは扱わない。

## 役割

このモデルは、各セルでどのような栽培・飼養が環境的に成立しうるかと、
それがどの程度まで実際に広がっているかを近似する。

目的は、農学的な収量を計算することではない。
生業モデルが読むために、「使える可能性」と「すでに使われている程度」を分けて持つことが目的である。

## 更新

まず、気候、水、地形、植生、土壌から、その場所で成立しやすい利用型を評価する。
湿った低地に向くもの、乾いた草地に向くもの、冷涼な高地に向くもの、森林縁に向くものなど、
環境に対する向き不向きを大まかに分ける。

次に、環境だけを見た成立可能性を決める。
これは「その場所で使える条件があるか」を表すだけで、実際に人が利用していることは意味しない。

実際の普及度は、成立可能性に加えて、前の時間ステップの状態、近くからの広がり、交易や移住のような非局所的な接触、
人口圧による集約化の影響を受ける。
環境に合っていても、まだ届いていないものはすぐには普及しない。
環境に合わないものは、接触があっても広がりにくい。

初めて有効になる時代では、成立しやすい場所の一部に起点を置く。
その後は、環境条件と接触の両方に従って、利用が少しずつ広がる。

## 接続

このモデルは、気候、水、地形、植生、土壌、人口圧、接触圧を読む。
出力する普及度は、生業モデルが農耕・牧畜の比率を決めるために読む。

このモデルは、食料生産量そのものは決めない。
食料供給や生活様式への変換は、生業側の責務である。

## 参照している考え方

現在のモデルは、次の考え方を組み合わせた近似である。

- 栽培・飼養には環境ニッチがある
- 成立可能性と実際の普及は別である
- 普及には時間遅れと空間的な広がりがある
- 交易、移住、人口圧は、自然拡散とは別の広がりを作る
- 複数の利用型は、単一の最適解ではなく混合として扱う

## 意図的な近似

このモデルでは、個別種の分類学的な厳密さ、品種改良、収量、栽培技術、病害、制度的な選択は直接扱わない。
また、特定地域の歴史的な伝播を再現することも目的ではない。

代わりに、環境に合うものが、接触と時間を通じて広がるという関係を安定して表すことを優先する。
