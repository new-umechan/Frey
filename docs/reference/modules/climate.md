# 気候の考え方

この文書は、現在の気候モデルを、実装の細部ではなく概念として説明する。
関数名、内部フィールド名、式、個別パラメータの一覧はここでは扱わない。

## 役割

気候モデルは、地形と海陸分布から、各セルの平均的な温度、水分、乾きやすさを作る。
目的は、天気を再現することではなく、長い時間スケールで水文・生態・社会モデルが読める
安定した気候場を与えることである。

ここで扱う気候は、年平均に近い背景条件である。
季節、日変化、短期の嵐、局地的な前線は直接扱わない。

## 更新

まず緯度と標高から、各セルの大まかな温度を決める。
高緯度ほど冷え、高い場所ほど冷える。
海に近い場所では、海が温度をならす効果も加わる。

次に、水蒸気の供給と移動を近似する。
海や湿った陸から水分が供給され、風に相当する向きに沿って周囲へ運ばれる。
水分を含んだ空気が上昇しやすい場所では雨が増え、下降しやすい場所や海から遠い場所では雨が減る。

山地は雨の分布を変える。
風上側では雨が増えやすく、風下側では乾きやすい。
この効果は地形をそのまま細かく解くのではなく、周囲との高さの差と海からの届きやすさで近似する。

最後に、降水、蒸発散、流出、乾燥度を整える。
雨が多く、蒸発に使える水が残る場所では湿潤になりやすい。
雨が少なく、蒸発需要が大きい場所では乾燥しやすい。

## 接続

気候は、地形から高さ、緯度、海陸、海からの距離を読む。
植生が育った後の時代では、地表の覆われ方も蒸発散に影響する。

気候が出す温度、降水、流出、乾燥度は、河川、氷、植生、生業の基礎条件になる。
そのため、気候場は時間ステップごとに過剰に跳ねず、地形や海陸の変化に遅れて追従する。

## 参照している考え方

現在のモデルは、次の考え方を組み合わせた近似である。

- 緯度と標高が平均気温を大きく決める
- 海は水分供給源であり、温度変化をならす
- 風向と地形は雨の増減を左右する
- 湿った空気が上昇すると雨が増え、下降すると雨が減る
- 植生は水を保持し、蒸発散を通して地表の湿り方に影響する

## 意図的な近似

このモデルでは、大気の三次元流れ、季節循環、日射の詳細、雲物理、嵐の発生は直接解かない。
代わりに、世界生成で必要な平均的な気候の差を、少ない計算量で安定して出すことを優先する。

そのため、局地的な気象の正確さよりも、地形と海陸に対して説明しやすい温度・雨・乾燥度の分布を重視する。
