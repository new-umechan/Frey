# 08 校正と検証仕様

## 1. 目的

パラメータ校正と回帰検証の手順を固定し、正否判定を定量化する。

## 2. 校正対象

- プレート回転パラメータ
- U寄与の重み
- ストリームパワー指数m, n
- 拡散係数κ
- K変調関数fの係数

## 3. 最小検証セット

1. 剛体回転整合性
2. 境界分類整合性
3. U寄与分解整合性
4. 侵食と拡散の符号整合性
5. 降水増加時のK単調性
6. 長時間積分の安定性
7. 同一条件での決定性

## 4. 指標

- 標高分布の平均、分散、歪度
- 主要河川流量上位合計
- 境界タイプ別の平均U
- 降水と侵食の相関係数
- 質量収支残差

## 5. 受け入れ基準

- 全検証セットが閾値内
- 決定性試験で完全一致
- 収支残差が許容範囲内

## 6. 運用

- 固定seedセットで定期回帰する
- 閾値更新時は理由と比較結果を記録する
