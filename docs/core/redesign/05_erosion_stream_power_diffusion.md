# 05 侵食仕様

## 1. 目的

侵食をストリームパワー項と拡散項の組で定義する。

## 2. ストリームパワー侵食

各セルiの侵食量Eiを次で表す。

```text
E_i = K_i * q_i^m * S_i^n
```

- Ki: 侵食係数
- qi: 集水後流量
- Si: 局所勾配
- m, n: 感度指数

## 3. 拡散項

地形平滑化をラプラシアン拡散で表す。

```text
D_i = κ * ∇²h_i
```

必要に応じて勾配依存の非線形拡散へ拡張する。

## 4. 水文計算の順序

1. 降水Pから流量源を生成する
2. 流向nextを決める
3. 上流からqを集積する
4. EとDを評価する

## 5. 境界・海岸の扱い

- 内陸盆地は溢流ルールで接続する
- 海岸遷移セルは堆積寄り補正をかける
- 深海セルは輸送系外損失を許可する

## 6. 安定化

- EとDにそれぞれ上限を設ける
- 平坦地でのゼロ割れを回避する
- 侵食と堆積の質量収支ログを保存する
