# 01 共通基盤仕様

## 1. 目的

4点セットを一貫して結合するため、記号、単位、状態量、時間離散を先に固定する。

## 2. 座標とメッシュ

- 空間は単位球面上の頂点集合で表す
- 各頂点を1セルとして状態量を持つ
- 近傍はCSR形式で管理する

## 3. 時間管理

- 世界時間をTickで管理する
- 地形内部時間はサブステップで管理する
- 1サブステップの幅をΔtとする

## 4. 状態量

- 地形: 標高h
- プレート: plate_id、回転軸ω
- 水文: 流量q、流下先next
- 気候: 降水P、温度T
- 侵食: 侵食係数K、侵食量E、拡散量D
- 鉛直運動: U

## 5. 主方程式の記法

地形更新は次で統一する。

```text
dh/dt = U - E + D
```

離散時間では次を使う。

```text
h(t+Δt) = h(t) + Δt * (U - E + D)
```

## 6. 数値安定条件

- 1ステップの標高変化量に上限を設ける
- 海面近傍の符号反転はヒステリシスで抑制する
- 近傍走査順依存を避けるため、更新はバッファ方式で行う

## 7. 決定性要件

- 同一seed + 同一params + 同一サブステップ列で同一結果になること
- 乱数を使う場合は状態を明示保存すること
