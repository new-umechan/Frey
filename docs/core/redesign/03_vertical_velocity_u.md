# 03 鉛直速度U仕様

## 1. 目的

地殻の鉛直変動を、境界タイプ、薄板近似、アイソスタシーでパラメタ化する。

## 2. 合成式

各頂点iの鉛直速度Uiを次で定義する。

```text
Ui = U_boundary_i + U_thinplate_i + U_isostasy_i
```

## 3. 境界タイプ項

境界辺の速度分解に基づき、収束、発散、横ずれを分類する。

- 収束: 造山と沈み込みを正負で配分する
- 発散: リフト沈降と新生地殻を配分する
- 横ずれ: 直接の鉛直寄与は小さく、二次項で扱う

## 4. 薄板項

薄板近似として、曲率と応力の平滑化項を導入する。

```text
U_thinplate = λ1 * curvature + λ2 * stress_relax
```

## 5. アイソスタシー項

局所標高と基準平衡標高との差に比例する緩和項で表す。

```text
U_isostasy = -λiso * (h - h_eq)
```

## 6. パラメータ群

- 境界強度係数
- 薄板係数λ1, λ2
- アイソスタシー係数λiso
- 境界再分類間隔

## 7. 要件

- 各寄与項は個別にON/OFFできる
- Uの寄与分解をデバッグ出力できる
