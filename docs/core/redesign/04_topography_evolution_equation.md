# 04 地形進化主方程式仕様

## 1. 目的

鉛直速度Uと侵食系を一つの更新則で結合する。

## 2. 連続形

```text
dh/dt = U - E + D
```

- U: 造構運動とアイソスタシーを含む鉛直速度
- E: 侵食による標高低下
- D: 拡散や堆積再配分による標高増減

## 3. 離散更新

```text
h_{n+1} = h_n + Δt * (U_n - E_n + D_n)
```

## 4. サブステップ分割

- 1Tick内でN回のサブステップを実行する
- Nは時代と活動度に応じて可変とする
- Uは毎サブステップ更新、気候は低頻度更新を許可する

## 5. 制約

- 海面下の過剰沈降を抑える下限制約を持つ
- 1サブステップの絶対変化量に上限を設ける
- 傾斜が不連続に増えた場合は拡散を優先する
