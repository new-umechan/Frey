# 07 結合実行仕様

## 1. 目的

4点セットを決定的に実行するため、1Tick内の演算順と同期規約を固定する。

## 2. 1Tick内の標準順序

1. プレート回転から接線速度を更新する
2. 境界分類と鉛直速度Uを更新する
3. 気候を必要周期で更新し、降水PとKを更新する
4. 水文計算からqとnextを更新する
5. EとDを計算し、hを更新する
6. 収束判定用メトリクスを更新する

## 3. サブステップ規約

- 地形サブステップ数Nterrainを持つ
- 気候更新周期Nclimateを持つ
- NterrainとNclimateは整数で管理する

## 4. 同期規約

- 同一サブステップでは入力場を固定し、出力場を別バッファへ書く
- コミット点でのみ状態を交換する
- 交換順は全サブシステムで固定する

## 5. 失敗モード

- 変化量上限超過
- NaNまたは無限値の発生
- 収束指標の長期非改善

発生時は強制クリップ、サブステップ縮小、診断ログ保存を順に適用する。
