# 06 気候仕様

## 1. 目的

風駆動循環から降水場を生成し、侵食係数Kを空間変調する。

## 2. 流れ

1. 緯度帯と地形から風場Wを近似する
2. Wと標高から降水場Pを計算する
3. Pと温度TからKを更新する

## 3. 降水場

降水は次の要因で構成する。

- 背景循環降水
- 地形性降水
- 雨陰減衰

## 4. K変調

侵食係数は基準値K0に対して次で与える。

```text
K_i = K0 * f(P_i, T_i, biome_i)
```

初版ではbiomeは省略可能で、fは単調増加の有界関数とする。

## 5. 更新頻度

- 気候場は毎サブステップでなくてもよい
- Kの更新は地形更新より粗い間隔を許可する
- 更新しない区間では直前値を保持する

## 6. 要件

- Pが増える領域でKが下がらないこと
- Kの上下限を明示すること
- 乾燥域と湿潤域で侵食差が再現されること
