# 02 プレート運動仕様

## 1. 目的

プレート運動を、観測整合しやすい球面剛体回転として定義する。

## 2. 表現

各プレートpに対して、オイラー回転ベクトルΩpを持つ。

- 方向: 回転極
- 大きさ: 角速度

## 3. 頂点速度

位置ベクトルxを持つ頂点の接線速度vは次で与える。

```text
v = Ωp × x
```

ここでpは頂点のplate_idに対応する。

## 4. 境界相対速度

境界辺(i, j)の相対速度は次で定義する。

```text
Δv = vj - vi
```

Δvを法線方向成分と接線方向成分に分解し、境界タイプ判定に渡す。

## 5. 観測同化

- 観測がある場合はΩpの事前分布を更新する
- 観測がない場合はseed依存の初期分布から生成する
- 更新単位はプレートごとに独立とする

## 6. 出力

- 頂点接線速度v
- 境界相対速度Δv
- 境界分類に必要な速度分解量
