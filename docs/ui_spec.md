### 機能

再生機能 動画のように、再生、停止、巻き戻しができるように
介入機能
ログ機能
	サイドバーに、起こった主なイベントを記録していく
	クリックすると、そのイベントまで飛ぶことができる。
書き出し/読み込み機能 他の人のFreyを、介入なしに、再生のみできる。
